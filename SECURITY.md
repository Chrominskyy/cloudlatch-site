# Security policy

## Private reporting
Private vulnerability reporting is enabled for this repository. Report suspected vulnerabilities in CloudLatch or its website using [Report a vulnerability](https://github.com/Chrominskyy/cloudlatch-site/security/advisories/new). A GitHub account is required.

Include the affected version, impact, reproduction steps using fictional data, and any relevant sanitized evidence. Keep exploit details out of public issues and pull requests. Never send actual AWS keys, session tokens, MFA codes, credential files or personal data, even in a private report.

If credentials may have been exposed, revoke or rotate them through the relevant provider independently of this report. Do not wait for a maintainer response.

## Scope and coordination
This public repository receives reports for the CloudLatch application and website; application source is maintained separately. The app is being prepared for distribution, and no released-version support window is currently declared.

The maintainer will assess reports and coordinate remediation and disclosure through the private advisory. No fixed response time, resolution deadline or bounty is promised.
