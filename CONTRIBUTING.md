# Contributing and support

## Reports
Use [New issue](https://github.com/Chrominskyy/cloudlatch-site/issues/new/choose) and select:
- **Bug report** for a reproducible defect.
- **Incident report** for an interruption or operational impact.
- **Feature request** for an improvement.
- **Support question** for setup or troubleshooting.

English and Polish reports are welcome. Search existing issues first. Provide the affected version, expected and actual behavior, and minimal reproduction steps. Incidents should also include impact, timeline with timezone, current status and any workaround.

All issues and attachments are public. Use fictional AWS identifiers. Never post keys, session tokens, MFA codes, account IDs, ARNs, credential/profile files, private infrastructure details or unredacted logs and screenshots. Report suspected vulnerabilities or credential exposure through the [private security channel](SECURITY.md).

Labels classify reports; a label does not promise priority or a response deadline. Maintainers can request more information, merge duplicates and close resolved or out-of-scope reports.

## Website changes
This repository contains the public website and support material. Application source is maintained separately. Follow [AGENTS.md](AGENTS.md), keep changes focused and open a pull request to main. Explain the result and verification; include screenshots for visible changes. The repository owner is listed in CODEOWNERS.

Public visibility does not grant a license to redistribute the application, product branding or repository content. No open-source license is currently granted here.
